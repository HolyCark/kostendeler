# Waarnemingen

Toont recente natuurwaarnemingen van [waarneming.nl](https://waarneming.nl) rond je huis op een kaart.

## Instellingen

- **radius**: zoekstraal in meters (500 t/m 10000)
- **days**: hoeveel dagen terug (1 t/m 30)
